SH!VA WEB SCANNER v6.0 
By Ahmad Hamad

==================================================
DESCRIPTION
===========

SH!VA Web Scanner is an advanced web reconnaissance
and defensive security auditing platform designed
for educational and authorized security testing.

Features include:

* Security headers analysis
* Technology detection
* API & endpoint discovery
* DOM XSS review points
* CSRF review points
* Subdomain discovery
* Dashboard & reporting
* Live request viewer
* AI assistant modules
* Attack surface mapping

==================================================
HOW TO USE
==========

1. Run ShivaScanner.exe
2. Enter target URL
3. Click START SCAN
4. Review findings in dashboard tabs
